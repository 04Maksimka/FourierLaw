# Одномерная цепочка FPU-β с термостатом Ланжевена

Численная реализация к статье  
**«Одномерная цепочка осцилляторов с нелинейным взаимодействием»**.

---

## Физическая модель

### Гамильтониан

$$H = H_2 + \varepsilon H_4$$

$$H_2 = \tfrac{1}{2}\sum_j \bigl[p_j^2 + q_j^2 + (q_{j+1}-q_j)^2\bigr]$$

$$H_4 = \tfrac{1}{4}\sum_j (q_{j+1}-q_j)^4$$

### Уравнение движения (с термостатом)

В переменных взаимодействия $a_{\zeta}$ на медленном времени $\tau = \gamma t$:

$$\dot{a}_\zeta = \rho\,\Psi_\zeta(a,\tau\gamma^{-1}) - a_\zeta + \dot{\tilde{\beta}}_\zeta$$

где $\rho = \varepsilon/\gamma$, $\Psi_\zeta$ — нелинейность (кубическая по $a$),  
$\tilde\beta_\zeta$ — комплексное броуновское движение.

## API

### `OscillatorChain`
```python
chain = OscillatorChain(
    L=1001,          # число осцилляторов
    gamma=0.05,      # термостат (γ=0 → чисто гамильтонова система)
    varepsilon=0.2,  # нелинейность FPU-β
    T_slow=20.0,     # длительность в τ = γt
    seed=42,
)
chain.solve(q0=q0, p0=p0, n_store=800)
```

| Метод | Описание |
|---|---|
| `solve(q0, p0, n_store)` | Запустить интегрирование |
| `plot_hamiltonian()` | $H(\tau)$, $H_2(\tau)$, $\varepsilon H_4(\tau)$ |
| `plot_mode_energies(modes)` | FPU-спектр: $E_k(\tau)$ |
| `plot_particle_energy(i)` | Локальная энергия частицы $i$ |
| `plot_phase_portrait(i)` | Фазовый портрет $(q_i, p_i)$ |
| `plot_summary(...)` | Сводный дашборд |

### Данные после `solve`

| Атрибут | Форма | Описание |
|---|---|---|
| `tau_arr` | `(N,)` | Медленное время $\tau$ |
| `a_arr` | `(N, L, 2)` | Переменные взаимодействия $a_{k,\sigma}$ |
| `q_arr`, `p_arr` | `(N, L)` | Физические координаты |
| `H_arr`, `H2_arr`, `H4_arr` | `(N,)` | Гамильтониан и его части |

## Численная схема

**Эйлер–Маруяма** (физическое время):

$$a_{n+1} = a_n + f(a_n, t_n)\,\Delta t + \sqrt{\gamma\,\Delta t}\;\xi_n, \quad \xi_n \sim \mathcal{CN}(0,1)$$

Симметрия $a_{k,-1} = \overline{a_{-k,+1}}$ восстанавливается после каждого шага.
